Bab 4 – CSS Framework

4.1 Pengenalan

CSS Framework adalah kumpulan library CSS yang siap digunakan untuk mempercepat proses pembuatan tampilan website. Framework menyediakan layout dan komponen yang responsif.

4.2 Bootstrap 5

Grid System

Sistem layout responsif menggunakan baris dan kolom.

<div class="row">
  <div class="col-6">50%</div>
  <div class="col-6">50%</div>
</div>

Komponen UI

<button class="btn btn-primary">Tombol</button>

4.3 Tailwind CSS

tailwind.html 
<button class="bg-blue-500 text-white font-bold py-2 px-4 rounded">
  Tombol Saya
</button>

4.4 Perbandingan

Perbandingan Framework

Fitur Bootstrap 5 Tailwind CSS
Pendekatan Komponen Siap Pakai (Instan) Utility Classes (Fleksibel)
Customisasi Agak sulit (Override CSS) Sangat mudah
