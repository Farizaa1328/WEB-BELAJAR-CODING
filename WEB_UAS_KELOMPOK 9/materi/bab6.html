Bab 6 – Form & Validasi

6.0 Pengenalan

Formulir Web

Form digunakan untuk menerima input dari pengguna seperti nama, email, password, dan data lainnya sebagai media interaksi antara pengguna dan sistem.

6.1 Manipulasi Form

script.js 
let input = document.getElementById('nama');
let nilai = input.value; // Ambil nilai
input.value = "Otomatis"; // Isi nilai

6.2 Validasi Input

validasi.js 
if (email === "") {
    alert("Email wajib diisi!");
    return false;
}
