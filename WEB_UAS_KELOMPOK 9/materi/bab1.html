Bab 1 – Pengenalan Website

1.1 Definisi

Website adalah kumpulan halaman yang saling terhubung dan dapat diakses melalui jaringan internet menggunakan browser. Website digunakan untuk menyampaikan informasi, layanan, maupun media interaksi.

1.2 Statis vs Dinamis

Website Statis

Konten tetap, manual, dan sederhana.

  • Hanya HTML & CSS
  • Tidak ada database
  • Performa sangat cepat
  • Contoh: Portofolio, Landing Page

Website Dinamis

Konten berubah, interaktif, dan kompleks.

  • HTML, CSS, JS + Backend
  • Terhubung Database
  • Bisa Login & Input Data
  • Contoh: E-commerce, Portal Berita

1.3 Komponen Utama

Tiga teknologi fondasi pembentuk website modern (The Big Three):

HTML

Struktur
Menyusun kerangka dan konten halaman.

CSS

Tampilan
Mengatur gaya, warna, dan layout visual.

JavaScript

Interaksi
Membuat website dinamis dan interaktif.

1.4 Tools

Beberapa tools yang umum digunakan dalam pembuatan website:

Text Editor

Tempat menulis kode program (VS Code, Sublime Text).

Web Browser

Menampilkan hasil kode (Chrome, Firefox, Edge).

Web Server

Menjalankan website lokal (XAMPP, Laragon).

Git & GitHub

Menyimpan dan mengelola versi kode (Version Control).

1.5 Praktikum

Latihan 1: Hello World

Pada praktikum ini, kita akan mempraktikkan cara membuat file HTML pertama. Silakan ketik kode berikut di text editor Anda dan simpan dengan nama latihan1.html. 

<!DOCTYPE html>
<html>
<head>
    <title>Website Pertamaku</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah halaman website pertama saya.</p>
    <!-- Contoh menampilkan gambar -->
    <img src="https://via.placeholder.com/400x200?text=Gambar+Saya" alt="Contoh Gambar" width="400">
</body>
</html>
