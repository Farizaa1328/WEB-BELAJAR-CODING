Bab 3 – CSS3 & Layout

3.1 Pengenalan

CSS3 adalah teknologi yang digunakan untuk mengatur tampilan dan layout halaman website. Dengan CSS3, halaman web dapat dibuat lebih menarik, rapi, dan responsif.

3.2 Selektor & Properti

Selektor digunakan untuk memilih elemen HTML yang akan diberi gaya, sedangkan properti menentukan jenis tampilan yang diatur.

Rumus Dasar CSS

selektor {
    properti: nilai;
}

/* Contoh */
h1 { color: blue; }

Jenis Selektor

Selektor Simbol Target
Tag p Semua <p>
Class .btn class="btn"
ID #unik id="unik"

3.3 Box Model

Struktur Box Model

Setiap elemen HTML adalah kotak yang terdiri dari lapisan-lapisan berikut:

  • ■ Margin: Ruang kosong di luar border.
  • ■ Border: Garis tepi elemen.
  • ■ Padding: Ruang antara konten dan border.
  • ■ Content: Isi elemen sebenarnya.
.box {
  margin: 20px;   /* Luar */
  border: 5px solid gold;
  padding: 20px;  /* Dalam */
}

3.4 Warna & Tipografi

Styling Text

CSS digunakan untuk mengatur warna, ukuran font, dan jenis huruf agar tampilan lebih nyaman dibaca. 

.teks-info {
    color: #d4af37;
    font-family: 'Poppins', sans-serif;
    font-size: 18px;
}

3.5 Flexbox & Grid

Flexbox (1 Dimensi)

Mengatur elemen dalam satu baris atau kolom.

.container {
  display: flex;
  justify-content: center;
}

Grid (2 Dimensi)

Mengatur elemen dalam baris dan kolom sekaligus.

.galeri {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

3.6 Animasi

Transisi & Transformasi

CSS3 memungkinkan elemen bergerak atau berubah bentuk saat berinteraksi. Arahkan kursor ke kotak di samping untuk melihat efeknya! 

.box {
    transition: transform 0.5s;
}

.box:hover {
    transform: scale(1.1) rotate(10deg);
}
