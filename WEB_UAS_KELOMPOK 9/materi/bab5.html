Bab 5 – JavaScript Modern

5.1 Pengenalan

JavaScript Modern

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi interaktif dan dinamis.

5.2 Variabel & Tipe Data

JavaScript menyediakan variabel var, let, dan const. Tipe data meliputi string, number, boolean, array, dan object.

script.js 
const umur = 21; // Tetap
let skor = 0;    // Bisa berubah
const hobi = ["Koding", "Gaming"];

5.3 Logika & Loop

logika.js 
if (nilai >= 75) {
  console.log("Lulus");
}
loop.js 
for (let i = 0; i < 5; i++) {
  console.log(i);
}

5.4 Fungsi & ES6+

Fungsi digunakan untuk menjalankan kode secara berulang. ES6+ menghadirkan fitur modern seperti arrow function dan template literal.

fungsi.js 
// Cara Modern (Arrow Function)
const sapa = (nama) => {
    return `Halo ${nama}`; // Template Literal
}

5.5 DOM

DOM memungkinkan JavaScript mengakses dan memanipulasi elemen HTML seperti teks, atribut, dan style.

dom.js 
const judul = document.getElementById('judul');
judul.innerText = "Teks Berubah!";
judul.style.color = "yellow";

5.7 Praktikum

🎯 Misi Anda:

Buat tombol toggle yang mengubah warna background halaman (simulasi).

Simulasi Aplikasi

Ini adalah konten contoh.

const body = document.body;
const btn = document.getElementById('toggle');

btn.addEventListener('click', () => {
  body.classList.toggle('dark-mode');
});
