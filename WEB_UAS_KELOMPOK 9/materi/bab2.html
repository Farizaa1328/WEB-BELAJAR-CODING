Bab 2 – HTML Dasar

2.1 Pengenalan HTML5

Apa itu HTML5?

HTML5 adalah versi terbaru dari HyperText Markup Language yang digunakan untuk membangun struktur halaman website modern. HTML5 menghadirkan elemen semantik yang membuat kode lebih rapi, mudah dipahami, dan ramah SEO.

HTML5 tidak hanya menampilkan teks, tetapi juga mendukung multimedia, form interaktif, serta integrasi dengan CSS dan JavaScript.

2.2 Struktur Dasar HTML

Kerangka Dasar

Setiap dokumen HTML memiliki struktur dasar sebagai berikut:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Judul Halaman</title>
</head>
<body>
    Konten website
</body>
</html>

Struktur ini wajib digunakan agar browser dapat membaca dan menampilkan halaman dengan benar.

2.3 Teks & Format

Formatting Text

HTML menyediakan berbagai tag untuk mengatur teks, seperti:

  • <h1> – <h6> : Judul
  • <p> : Paragraf
  • <strong> : Teks tebal
  • <em> : Teks miring
  • <br> : Baris baru

2.4 Link & Navigasi

Hyperlink

Link digunakan untuk menghubungkan halaman satu dengan lainnya.

<a href="home.html">Menuju Home</a>

2.5 List & Table

List & Tabel

HTML memiliki dua jenis list utama:

  • Ordered List (<ol>)
  • Unordered List (<ul>)
<table>
  <tr>
    <th>Nama</th>
    <th>NIM</th>
  </tr>
  <tr>
    <td>Andi</td>
    <td>12345</td>
  </tr>
</table>

2.6 Formulir

Input Form

Form digunakan untuk menerima input dari pengguna.

<form>
    <input type="text" placeholder="Nama">
    <input type="email" placeholder="Email">
    <button>Kirim</button>
</form>

2.7 Multimedia

<video controls>
    <source src="video.mp4" type="video/mp4">
</video>
